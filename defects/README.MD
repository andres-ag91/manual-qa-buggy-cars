# Defect Reports & Bug Evidence

This folder contains the defect reports identified during the Manual QA testing project for the Buggy Cars web application.

## Documented Defects

- BCR-01 – Registration fails with a valid password
- BCR-02 – Register button is enabled for an invalid password length
- BCR-03 – Login succeeds but the application does not navigate to the expected home page
- BCR-04 – Register button is enabled when the password does not contain an uppercase letter

## Defect Information

Each defect report includes:

- Defect ID
- Title
- Severity
- Priority
- Environment
- Preconditions
- Steps to reproduce
- Expected result
- Actual result
- Evidence
- Defect status

The complete project overview is available in the main [README](../README.md).
