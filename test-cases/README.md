# Test Cases & Test Execution

This folder contains the test cases designed and executed during the Manual QA testing project for the Buggy Cars web application.

## Contents

- Functional test cases
- Positive and negative test scenarios
- Boundary value testing
- Test execution results
- Pass/Fail status
- Traceability between requirements and test cases

The test cases were designed based on the available application requirements and acceptance criteria.

The complete project overview is available in the main [README](../README.md).
