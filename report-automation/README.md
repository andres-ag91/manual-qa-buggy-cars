# QA Report Automation Scripts

This folder contains automation scripts developed with the assistance of AI to simplify repetitive QA documentation tasks and improve the efficiency of test documentation workflows.

The scripts automate the translation of test documentation and the generation of structured bug reports using Google Sheets and Google Docs.

## 1. Google Sheets Translation Script

**Purpose:** Automatically translate a Google Sheets test documentation spreadsheet from Spanish to English and create a separate copy of the translated spreadsheet.

**Key features:**
- Translates spreadsheet content from Spanish to English.
- Creates a separate copy, preserving the original Spanish version.
- Reduces repetitive manual translation work.
- Helps maintain test documentation in both Spanish and English.

**Output:** A separate English version of the original Google Sheets spreadsheet.

## 2. Automated Bug Report Generator

**Purpose:** Extract relevant data from Google Sheets and automatically generate structured bug report documents in Google Docs.

**Key features:**
- Retrieves bug report information from Google Sheets.
- Generates formatted bug reports in Google Docs.
- Supports report generation in Spanish or English.
- Reduces manual document preparation and formatting.
- Helps maintain consistent bug report documentation.

**Output:** A Google Docs bug report document in the selected language.

## Technologies & Tools

Google Apps Script | Google Sheets | Google Docs | AI-Assisted Development

## Project Objective

These scripts demonstrate how automation can improve QA workflows by reducing repetitive documentation tasks, supporting bilingual reporting, and standardizing the preparation of test documentation.

AI assistance was used during script development, with the goal of applying automation to practical software testing and quality assurance activities.
