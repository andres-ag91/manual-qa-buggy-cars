# Project Overview

## Project: Buggy Cars Rating — Manual QA Testing

This project demonstrates a structured manual software testing workflow applied to the Buggy Cars Rating web application. It focuses on validating application functionality, identifying inconsistencies between expected and actual behavior, and documenting defects clearly.

The project was developed as a QA portfolio project to demonstrate practical skills in functional testing, exploratory testing, test case design, and defect reporting.

## Project Objectives

- Validate key application functionalities through manual testing.
- Design and execute structured functional test cases.
- Perform exploratory testing to investigate application behavior.
- Identify and document software defects with clear reproduction details.
- Organize QA documentation to support traceability and communication.

## Scope

The project includes **26 functional test cases**, **4 exploratory tests**, and **4 documented bug reports**.

Testing focuses on application behavior, input validation, registration, login, and inconsistencies between the observed behavior and the expected results defined for the tests.

## Testing Approach

Testing was performed manually using a browser. Test cases and results were organized in spreadsheets, while defects were documented in structured bug reports.

Google Sheets, Google Docs, and Google Apps Script were used to support test documentation and automate repetitive reporting tasks. AI assistance was used in developing the documentation automation scripts.

## Project Deliverables

- Functional test cases and execution results.
- Exploratory testing documentation.
- Bug reports documenting identified defects.
- Automation scripts for spreadsheet translation and bug report generation.
