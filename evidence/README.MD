# Test Evidence

This folder contains the evidence collected during the Manual QA testing project for the Buggy Cars web application.

## Evidence Types

The evidence may include:

- Screenshots of failed test cases
- Screenshots showing application behavior
- Screenshots supporting defect reports
- Relevant UI validation results

Evidence is linked to the corresponding test case and defect report to maintain traceability.

## Defect Evidence

Evidence related to the documented defects is organized using the following IDs:

- BCR-01
- BCR-02
- BCR-03
- BCR-04

The complete project overview is available in the main [README](../README.md).
